# Правила перевода HoN RU Pack v2

## Формат

Каждая строка: `КЛЮЧ\t\tЗНАЧЕНИЕ`  
Разделитель - **TAB**. Допустимо несколько табов для выравнивания. Минимум один TAB.

## Приоритет категорий

| Категория | Приоритет | Ключи |
|---|---|---|
| Боевая механика | высокий | `Ability_*_description_simple`, `State_*_effect` |
| Предметы | высокий | `Item_*_description_simple` |
| UI / Интерфейс | средний | `options_*`, `main_*`, `lobby_*` |
| Системные сообщения | средний | `chat_*`, `showdown_*` |
| Лор / Атмосфера | низкий | `*_flavortext`, `*_tooltip_flavor` |

---

## Стиль перевода по категориям

### 1. Описания способностей (`Ability_*_description_simple`, `_description`)

**Структура:** `[Тип] [Действие] [Цель] [Эффект] [Числа]`

```
+ Наносит {100,150,200,250} маг. урона врагам в области 300. Замедляет на 2 сек.
- Активируйте способность чтобы нанести вражеским целям 100 урона...
- При использовании наносит {100,150,200,250} магического урона...
```

- Активный залог, настоящее время: **Наносит**, **Замедляет**, **Призывает**, **Телепортирует**
- Пассивные эффекты: **Пассивно:** или **При атаке:**, **При получении урона:**
- Ауры: **Аура:** в начале строки
- Не пиши "Вы", "Вас", "Ваш" - пиши **"цель"**, **"герой"**, **"себя"**
- SOTM (Staff of the Master): `_description2:ult_boost` -> **Посох Мастера:** в начале

### 2. UI / Интерфейс (`interface_en.str`)

```
+ Сохранить настройки        + Включить HDR
- Сохранить настройки.       - Активировать режим HDR
```

- **Инфинитив**: Сохранить, Включить, Настроить, Применить
- **Без точки** в конце
- Кнопки и вкладки - одно-два слова
- Настройки - кратко, без "Вы можете"
- Горячие клавиши (Shift, Ctrl, LMB) - **не переводить**

### 3. Лор / Flavortext (`_flavortext`, `_tooltip_flavor`)

```
+ "Даже камень трескается под этим клинком"
- Даже камень трескается под этим клинком
```

- Свободный художественный стиль
- Кавычки: обычные **"лапки"** - для ёлочек в игровом шрифте нет глифов
- Можно адаптировать - главное атмосфера
- Сохраняй мрачный/эпичный тон оригинала

### 4. Системные сообщения (`game_messages_en.str`, `client_messages_en.str`)

```
+ {player} убивает {victim}    + Курьер доставляет предмет
- Игрок {player} убил {victim}  - Ваш курьер доставил предмет
```

- Кратко, без "игрок", "ваш"
- Переменные `{player}`, `{victim}`, `{killer}` - **не переводить**, переносить как есть
- Пинги и команды - глагол в императиве: **"Защищать!"**, **"Атаковать!"**

## Что НЕ переводить

| Категория | Причина |
|---|---|
| Имена героев (`Hero_*_name`) | Оставить на английском |
| Состояния (`State_*_name`) | Оставить на английском |
| Названия предметов (`Item_*_name`) | Оставить на английском |
| Названия способностей (`Ability_*_name`) | Оставить на английском |
| Варианты имён с суффиксом (`*_name:ult_boost`) | Тоже английские - иначе у одной способности два имени |
| Коды цветов `^y ^r ^g ^o ^*` | Разметка движка |
| Переменные `{value}` `{player}` | Подстановка игры |
| Горячие клавиши `LMB` `Shift` `Ctrl` | Шрифт без кириллицы |
| Регионы `USE` `USW` `EU` | Технические коды |
| Popup-текст боя `Miss!` `Critical!` | Floating text без кириллицы |

## Правила сокращений (тултипы)

Тултип должен помещаться в ~90 символов. Используй сокращения:

| Полная форма | Сокращение |
|---|---|
| магический урон / магического урона | маг. урон / маг. урона |
| физический урон / физического урона | физ. урон / физ. урона |
| чистый урон / чистого урона | чист. урон / чист. урона |
| скорость передвижения / скорости передвижения | скор. движ. |
| скорость атаки / скорости атаки | скор. атаки |
| максимальное здоровье / максимального здоровья | макс. здоровье / макс. здоровья |
| регенерация здоровья / маны | реген. здоровья / маны |
| сопротивление магии | сопрот. магии |
| магическая броня | маг. броня |
| в секунду / за секунду | в сек. |
| дополнительный | доп. |
| секунды / секунд | сек. |
| перезарядка | перезарядка (не сокращать!) |
| длительность | длит. |

## Проверка качества

Перед сдачей перевода проверь:

- [ ] Нет русских букв в именах героев/способностей/предметов
- [ ] Все `^y ^r ^g ^o ^*` на месте, каждый открывающий - закрыт `^*`
- [ ] `{value}` не тронут, перенесён как в оригинале
- [ ] Горячие клавиши (LMB, Shift) на английском
- [ ] Регионы (EU, USW) на английском
- [ ] Тултипы не длиннее оригинала значительно (сокращения использованы)
- [ ] Описания способностей начинаются с глагола в активном залоге
- [ ] UI строки - инфинитив, без точки
- [ ] Flavortext - в кавычках, художественный стиль
- [ ] Нет "Вы" / "Ваш" / "Вас" в описаниях
- [ ] Посох Мастера: метка "Посох Мастера:"
- [ ] Файл сохранён в UTF-8 with BOM
