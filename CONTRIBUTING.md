# Как править перевод

## Структура

```
bundle/                 файлы перевода, копия апстрима - правь через overrides
|-- entities_en.str     умения, предметы, герои
|-- interface_en.str    интерфейс, меню, настройки
|-- client_messages_en.str
|-- game_messages_en.str
`-- bot_messages_en.str

linux/                  порт под Linux
|-- apply.sh            установка и режим --on-launch
|-- uninstall.sh        откат
|-- config.sh           поиск игры в wine-префиксах
|-- overrides.str       локальные правки строк
|-- untranslated.sh     отчёт о пробелах в переводе
|-- lint.sh             проверка bundle/ на дефекты
`-- lib/                honru.py (мерж, startup.cfg), probe.py (inotify)

docs/                   правила перевода
```

## Куда писать перевод

**Перевод идёт прямо в `bundle/`** - в родном формате апстрима, чтобы его
можно было отправить автору одним PR и чтобы он достался в том числе
Windows-пользователям. `make update` не перезаписывает файлы, а делает
трёхсторонний мерж, так что правки переживают обновление.

```
report_ui_header		Жалоба на игрока
```

**`linux/overrides.str` - только для того, что апстрим не примет.** Сейчас
там две строки: автор вписал в `main_label_username` и
`main_login_remember_me_tip` версию пакета и ссылку на Boosty, затерев
подпись поля логина и подсказку галочки "запомнить меня".

```
interface:main_label_username	Имя пользователя
```

Формат оверрайда: `<файл>:<ключ><TAB><значение>`, где `<файл>` - имя без
`_en.str`. Комментарии через `//`. Оверрайд накладывается поверх `bundle/`
при установке.

## Отправить перевод в апстрим

```sh
make pr NAME=translate-report-ui
git commit -m "translate: report UI"
git push origin translate-report-ui
```

Ветка растёт от `upstream/master` и содержит только изменения `bundle/`:
ни Linux-порта, ни оверрайдов - автору нужен перевод, а не наша сборка.

## Проверка

```sh
make lint                            # дефекты перевода
make untranslated                    # что осталось без перевода
make untranslated GROUP=интерфейс    # по группе, подробно
```

`make lint` ловит то, на чём перевод ломается в игре: переведённые имена,
расхождение чисел с данными способностей, потерянные подстановки, незакрытые
цветовые коды, латиницу внутри русского слова, невидимые символы и переведённые
служебные токены фильтров магазина. Обе цели сверяются с установленной игрой.

Потом `make run` и запустить игру - глазами в интерфейсе видно то, что не ловит
ни одна проверка.

Перевод берётся из `bundle/`, а база строк - из `resources0.jz`, поэтому
строки, которых нет в `bundle/`, остаются английскими, но не пропадают.

## Формат .str

`КЛЮЧ<TAB>ЗНАЧЕНИЕ`, кодировка UTF-8 (часть файлов с BOM), переводы строк CRLF.
Менять кодировку нельзя - движок перестанет читать файл. `honru.py` сохраняет
её автоматически.

Цветовые коды вида `^g ... ^*` и подстановки `{100,150,200}` переносятся как есть.
