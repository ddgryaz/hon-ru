# Как устроен порт под Linux

Установка - в [корневом README](../README.md).

## Когда подключается перевод

Лаунчер Juvio проверяет файлы игры и на любой лишний файл требует обновление.
Поэтому перевод не лежит в папке игры постоянно. `make run` (или строка в
параметрах запуска Steam) ждёт, пока лаунчер закончит проверку, и только тогда
подкладывает файлы перевода. После выхода из игры они убираются.

Английская основа при каждом запуске берётся из установленной игры, а сверху
накладывается перевод. Поэтому новые строки из патчей остаются на английском,
а не пропадают.

## Где ищется игра

Префиксы Proton во всех библиотеках Steam (включая flatpak), `$WINEPREFIX`,
`$STEAM_COMPAT_DATA_PATH`, `~/.wine`, Lutris и Bottles. Не нашлась - создайте
`linux/config.local.sh` (git его не трогает):

```sh
HON_GAME_DIR="/путь/до/AppData/Local/Juvio/heroes of newerth"
HON_DOCS_DIR="/путь/до/Documents/Juvio/Heroes of Newerth"
```

`HON_DOCS_DIR` можно не задавать, если префикс устроен стандартно.
