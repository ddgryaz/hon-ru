# hon-ru

![game version](https://img.shields.io/badge/game%20version-0.12.8.1-blue) ![last commit](https://img.shields.io/github/last-commit/ddgryaz/hon-ru)

Русский перевод Heroes of Newerth (HoN Reborn) для Linux: Proton, Lutris,
Bottles, чистый wine.

Основан на переводе
[Xyling12/HoN_RU_Pack](https://github.com/Xyling12/HoN_RU_Pack) и с тех пор
развивается самостоятельно.

## Что сделано

- **Работает под Linux.** С установщиком исходного проекта под Proton
  лаунчер уходит в бесконечное "требуется обновление". Здесь перевод
  подключается как мод из отдельного каталога: файлы игры не меняются, и
  лаунчеру не к чему придраться.
- **Актуален для текущей версии игры.** Описания переработанных героев и
  способностей были от старых версий, с другими цифрами урона, длительности и
  перезарядки. Цифры сверены с данными игры, переработанные описания
  переведены заново.
- **Вычищен машинный перевод.** Исправлены дословные и кривые фразы
  (`сек..`, `Длит.:`, `второе Оглушение`), единая терминология, переписаны
  системные сообщения, голосования, серии убийств, кнопки меню.
- **Ничего не сломано в интерфейсе.** Восстановлены потерянные плейсхолдеры
  (вместо чисел в подсказках было пусто), оборванные на полуслове строки,
  пропавшие абзацы, цвета. Убраны невидимые символы, из-за которых ломались
  карточки героев, и стрелки, которых нет в шрифтах игры. Вернулись предметы,
  пропадавшие из фильтров магазина.
- **Переведено то, что оставалось на английском**: жалобы, подбор игры,
  Mid Wars, обучение, чат-команды.
- **Есть проверки.** `make lint` ловит все эти классы ошибок, `make
  untranslated` показывает, что осталось без перевода. Оба сверяются с
  установленной игрой.

Это не полный список: мелких правок по всему переводу намного больше, и он
продолжает улучшаться.

> [!NOTE]
> Перевод сверен с версией игры **0.12.8.1**. После патча игры перевод не
> ломается: новые строки (герои, предметы, способности) остаются на
> английском, пока их не переведут.

## Установка

```sh
make launch-options
```

Скопируй выведенную строку в Steam -> ПКМ по игре -> Свойства -> Параметры
запуска. Всё: перевод собирается при каждом запуске и подключается к игре.

Нужны `make`, `python3` и `7z` (пакет p7zip).

Не через Steam (Lutris, Bottles, чистый wine): запускай игру командой
`linux/apply.sh <команда запуска игры>`, например через префикс команды в
настройках игры в Lutris.

Если игра не нашлась, создай `linux/config.local.sh` (он в `.gitignore`):

```sh
HON_GAME_DIR="/путь/до/AppData/Local/Juvio/heroes of newerth"
HON_DOCS_DIR="/путь/до/Documents/Juvio/Heroes of Newerth"
```

## Команды

| | |
|---|---|
| `make launch-options` | строка для параметров запуска в Steam |
| `make build` | собрать перевод без запуска игры |
| `make uninstall` | убрать перевод, вернуть `startup.cfg` |
| `make lint` | проверить `bundle/` на дефекты перевода |
| `make untranslated` | что осталось без перевода |

`make lint` и `make untranslated` сверяются с установленной игрой: эталон строк
берётся из `resources0.jz`.

## Обновление

```sh
git pull
```

Ничего переустанавливать не нужно: перевод собирается заново при каждом
запуске игры.

## Удаление

```sh
make uninstall
```

Удаляет архив перевода и ссылку профиля, возвращает `startup.cfg`. После
этого убери строку из параметров запуска.

Если лаунчер зациклился на "требуется обновление", в каталоге игры остались
файлы от прежней версии перевода. `make uninstall` это чинит, и при
следующем запуске с переводом они тоже убираются сами.
