# hon-ru-linux

Русский перевод Heroes of Newerth (HoN Reborn) для Linux: Proton, Lutris, Bottles, чистый wine.

Форк [Xyling12/HoN_RU_Pack](https://github.com/Xyling12/HoN_RU_Pack). От оригинала
отличается тем, что здесь **только перевод**: без фонового агента, обращений в
сеть, баннеров и обхода блокировок. Windows-обвязка (сборка `.exe`,
PowerShell-скрипты, CI) удалена - перевод в `bundle/` берётся из апстрима.

## Установка

```sh
make launch-options
```

Скопируй выведенную строку в Steam -> ПКМ по игре -> Свойства -> Параметры запуска.
Всё: перевод будет применяться при каждом запуске и убираться после выхода.

Проверить вручную, не трогая Steam:

```sh
make run     # затем запусти игру обычным способом
```

Нужны `python3`, `pgrep` и `make`.

## Как это работает

Лаунчер Juvio сверяет каталог игры со своим манифестом и считает установку
битой, если находит там лишний файл: требует обновление и вычищает каталог.
Поэтому перевод кладётся не заранее, а в окно между проверками лаунчера и
стартом движка, и убирается после выхода из игры.

Архив `resources0.jz` (8.5 ГБ) не трогается - откат сводится к удалению
нескольких файлов. Подробности, замеры и грабли: [linux/README.md](linux/README.md).

## Команды

| | |
|---|---|
| `make run` | применить перевод при запуске игры |
| `make probe` | то же плюс inotify-лог обращений движка к файлам |
| `make uninstall` | убрать перевод, вернуть `startup.cfg` |
| `make update` | подтянуть свежий `bundle/` из апстрима |
| `make diff-upstream` | посмотреть, что изменилось в апстриме |

## Обновление перевода

```sh
git remote add upstream https://github.com/Xyling12/HoN_RU_Pack.git   # один раз
make update
```

Забирается только `bundle/`, ветка целиком не мержится - иначе вернулась бы
удалённая Windows-обвязка.

## Правка строк

Свои правки перевода держи в [linux/overrides.str](linux/overrides.str) - они
накладываются поверх `bundle/` при установке, а сам `bundle/` остаётся копией
апстрима, поэтому `make update` проходит без конфликтов.

Правила перевода: [docs/TRANSLATION_GUIDE.md](docs/TRANSLATION_GUIDE.md),
[docs/ITEMS_GUIDE.md](docs/ITEMS_GUIDE.md).

## Что переведено

Интерфейс, описания способностей и предметов, системные сообщения.
