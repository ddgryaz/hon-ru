# hon-ru

![game version](https://img.shields.io/badge/game%20version-0.12.8.1-blue) ![last commit](https://img.shields.io/github/last-commit/ddgryaz/hon-ru)

Русский перевод Heroes of Newerth (HoN Reborn) для Windows и Linux (Proton,
Lutris, Bottles, чистый wine).

Переведены интерфейс, описания героев, способностей и предметов, системные
сообщения, чат-команды и обучение. Имена героев, предметов и способностей
намеренно оставлены английскими, как на кнопках в игре.

> [!NOTE]
> Перевод сверен с версией игры **0.12.8.1**. Герои, предметы и способности
> из более новых патчей будут на английском, пока их не переведут.

## Особенности

- **Не ломает запуск игры.** Перевод подключается при запуске и убирается
  после выхода, поэтому лаунчер не видит изменённых файлов и не требует
  бесконечно "обновить" игру.
- **Не ломается после патчей игры.** Английская основа берётся из
  установленной игры при каждом запуске: после обновления всё переведённое
  остаётся на русском, а новые строки просто идут по-английски.
- **Без машинного перевода.** Кривые и дословные фразы переписаны, термины
  едины по всей игре.
- **Интерфейс не ломается.** В подсказках на месте все числа и цвета, строки
  не обрываются, нет символов, которых нет в шрифтах игры.

## Установка

### Windows

1. Скачай [архив с переводом](https://github.com/ddgryaz/hon-ru/archive/refs/heads/master.zip)
   и распакуй туда, где он будет лежать постоянно, например в Документы.
   Ярлык будет вести в эту папку, так что потом её не переносить и не
   переименовывать.
2. Запусти `windows\install.bat`. На рабочем столе появится ярлык
   "HoN (RU)" - играй через него.

### Linux

Нужны `make`, `python3`, `pgrep` и 7-Zip 24.01 или новее (в Arch и Manjaro
пакет `7zip`; старый `p7zip` 16.02 архив игры не прочитает).

```sh
git clone https://github.com/ddgryaz/hon-ru.git
cd hon-ru
make run
```

Потом запусти игру как обычно. Скрипт дождётся её запуска, подключит перевод
и уберёт его после выхода, терминал пусть остаётся открытым. `make run`
нужен перед каждым запуском игры.

Если играешь через Steam, это можно не делать руками: `make launch-options`
выведет строку для Steam -> ПКМ по игре -> Свойства -> Параметры запуска.

## Обновление

Windows: скачай архив заново, распакуй поверх старой папки с заменой файлов
и ещё раз запусти `windows\install.bat`.

Linux: `git pull` в папке с переводом.

## Удаление

Windows: запусти `windows\uninstall.bat`, потом удали папку с переводом.

Linux: `make uninstall`. Если прописывал строку в параметры запуска Steam,
убери её.

## Частые вопросы

**Игра на английском.** На Windows игру надо запускать ярлыком "HoN (RU)":
родной ярлык Juvio и ссылки `hon://` запускают её без перевода. Ещё одна
причина - лаунчер как раз скачал патч игры: такой запуск идёт на английском,
со следующего всё как обычно. На Linux перед игрой должен быть запущен
`make run` (или прописана строка в Steam).

**Лаунчер требует обновление и не пускает в игру.** В папке игры остались
файлы перевода, например компьютер выключили прямо в игре. Запусти
`windows\uninstall.bat` или `make uninstall`, потом установи перевод заново.

**Игра не найдена.** Установи игру через лаунчер Juvio и дождись окончания
загрузки. Если игра перенесена вручную, путь к ней можно задать сам: как - в
[windows/README.md](windows/README.md) и [linux/README.md](linux/README.md).
