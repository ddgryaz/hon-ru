# Правила перевода hon-ru-linux

## Структура .str файла

Каждая строка в формате:
```
КЛЮЧ\t\t\tЗНАЧЕНИЕ
```
Разделитель - **TAB** (не пробелы). Несколько TAB'ов - нормально, для выравнивания. Главное - чтобы был хотя бы один TAB между ключом и значением.

Пустые строки и строки без TAB - игнорируются.

### Цветовые коды
В значениях встречаются `^y`, `^b`, `^r`, `^g`, `^!` и т.д. - это цвета. **Не трогать**, они управляют отображением текста в игре.

Пример из `bundle/entities_en.str`:
```
Ability_Nomad2_description_simple    Даёт ^rТочный удар^* и ^bУдар миража^*
```
-> "Точный удар" будет красным, "Удар миража" синим, `^*` возвращает
обычный цвет.

Каждый открывающий код закрывается `^*`. Незакрытый код красит весь текст
до конца тултипа.

### Числовые шаблоны
`{75,110,145,180}` - значения по уровням умения. **Не трогать**, игра подставляет их автоматически.

## Стиль перевода - главные правила

### Делай так:
- Активные глаголы в описаниях: **"Наносит"**, **"Замедляет"**, **"Призывает"**
- Игровой, живой русский язык
- Краткие descriptions - помещаются в тултип
- MOBA-термины из глоссария ниже

### Не делай так:
- `"Активируйте, чтобы нанести..."` -> `"Наносит..."`
- `"Выберите врага, чтобы..."` -> `"Атакует врага:"`
- `"Предоставляет вам..."` -> `"Даёт"` или `"Пассивно:"`
- `"Нацельтесь на союзника (или на себя)"` -> `"Применяется к союзнику или себе:"`
- Имена - **не переводить**: ни героев, ни способностей, ни предметов
  (Accursed остаётся Accursed, Chaotic Flames остаётся Chaotic Flames)

## Формат описаний умений

Умения имеют несколько полей:

| Ключ | Назначение | Переводим |
|---|---|---|
| `Ability_X_name` | Название способности | нет, остаётся английским |
| `Ability_X_name:ult_boost` | Название под Посохом Мастера | нет, иначе у способности два имени |
| `Ability_X_description_simple` | **Краткое описание** в тултипе - главное! | да |
| `Ability_X_description` | Полное описание (не всегда отображается) | да |
| `Ability_X_description2` | Дополнительный блок (Посох Мастера и т.д.) | да |
| `Ability_X_IMPACT_effect` | Механика в подробном тултипе | да |

Приоритет: `_description_simple`, затем остальные описания.

## Что НЕ переводить

- Имена героев: Accursed, Tundra, Magmus
- Названия способностей: `Ability_*_name` и варианты с суффиксом
  (`:ult_boost`, `:button2` и прочие) - иначе в игре у одной способности
  оказывается два разных имени
- Названия предметов: `Item_*_name`, включая варианты вида `Bottle (3/3)`
- Названия состояний и петов: `State_*_name`, `Pet_*_name`
- Игровые идентификаторы в `{}` скобках
- Цветовые коды `^X`, включая `^n` (коричневый) - его легко спутать
  с переносом строки `\n`

Правило про имена введено в v1.5 и закреплено в v1.9.9p: имена оставлены
английскими, чтобы совпадать с тем, что говорят в игре и на стримах.
