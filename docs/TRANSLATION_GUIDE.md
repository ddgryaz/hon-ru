# Правила перевода hon-ru-linux

Правила для правки строк в `bundle/*_en.str`. Предметы - отдельно, в
[ITEMS_GUIDE.md](ITEMS_GUIDE.md).

Оригинал для сверки - английские строки игры из `resources0.jz` (их извлекают
`make lint` и `make untranslated`). Файлы в `bundle/` - уже перевод, а не
оригинал.

## Структура .str файла

```
КЛЮЧ\t\t\tЗНАЧЕНИЕ
```

- Между ключом и значением пиши TAB. Несколько TAB подряд - выравнивание, их
  число не меняй: `make update` сливает файлы построчно, и строка, изменённая
  только табами, даст конфликт с апстримом.
- В файлах игры встречаются строки, где ключ отделён пробелами. Их тоже не
  переделывай, правь только значение.
- Кодировка UTF-8, часть файлов с BOM, переводы строк CRLF. Не меняй ни одно
  из трёх - движок перестанет читать файл.
- Пустое значение игнорируется, и в игре остаётся английский текст.

## Разметка

- Цветовой код - `^` и ровно один символ: `^o`, `^g`, `^r`, `^y`, `^!b`.
  `^*` возвращает обычный цвет. Каждый открытый код закрывай `^*`, иначе цвет
  растечётся до конца тултипа.
- `^;` выключает свечение, `^:` включает. `^*` свечение не сбрасывает,
  поэтому после ника в оригинале стоит `{player}^*^;`: без `^;` свечение
  цветного ника перетекает на весь текст сообщения. Переноси `^;` туда же,
  куда в оригинале. `^^;` - экранированная каретка (справка `/colors`), а не
  код. Полный список кодов - в `client_messages:chat_command_colors_line_*`.
- `^n` - это коричневый цвет, а не перенос строки. Перенос пишется `\n`.
- `{75,110,145,180}` - значения по уровням, игра сама подставляет нужное.
  Список обязан совпадать с оригиналом символ в символ. Не заменяй его одним
  числом: константа будет верна только на одном уровне. Тултип берёт числа из
  `.str`, а урон считается по данным способности, поэтому устаревший список
  показывает игроку не то, что он получит.
- Переменные вроде `{player}`, `{account_color}`, `{value}` переноси все и без
  изменений. Потерянная переменная - пустое место в сообщении.
- Сохраняй все абзацы: если в переводе меньше `\n`, чем в оригинале, почти
  всегда пропал целый абзац (эффект Посоха Мастера, строка Mid Wars).

## Что не переводить

- Имена героев, способностей, предметов, состояний, петов: все ключи
  `*_name`, включая варианты с суффиксом (`:ult_boost`, `:button2`). Иначе у
  одной способности в игре окажется два имени.
- Названия карт и режимов: Forests of Caldavar, Mid Wars, All Pick, Single
  Draft, Random Draft, Banning Pick, Banning Draft, Blind Ban, Lock Pick,
  Captains Draft, Counter Pick, Shuffle Pick, Hero Ban, Balanced Random и
  прочие режимы драфта. Опции лобби переводятся: No Leavers - "Без
  покинувших", No Bottom Lane - "Без нижней линии". Калдавар в лоре
  (биографии, flavor-тексты) - это место в мире, его пиши по-русски.
- Команды чата: значение ключа `chat_command_<имя>` - это сама команда
  (`/colors`, `/whisper`, `/w`). Переведённое значение ломает команду.
  Переводится только справка к ней (`*_info`, `*_line_*`, `*_message`).
- Служебные значения предметов (`*_shop_categories`, `*_search_terms`) - см.
  [ITEMS_GUIDE.md](ITEMS_GUIDE.md).

## Что ломает интерфейс

- Невидимые символы: неразрывный пробел `U+00A0` и zero-width `U+200B`. В
  описании способности они гасят героя в списке героев - он перестаёт
  подсвечиваться. Используй обычный пробел.
- Стрелок нет ни в одном шрифте игры, вместо них пустой квадрат. Пиши `->`.
  Тире, многоточие, кавычки-ёлочки и буллет в шрифтах есть.
- Длинные кнопки обрезаются. Короткие подписи и кнопки держи не длиннее
  английских. Во внутриигровом меню предел около 8 символов кириллицы:
  Remake - "Рестарт", Report - "Жалоба", Disconnect - "Покинуть", Exit HoN -
  "Выход".

## Стиль

- В описаниях способностей - действие в третьем лице: "Наносит",
  "Замедляет", "Призывает", "Даёт". Не "Активируйте, чтобы нанести...", не
  "Предоставляет вам...".
- На кнопках - инфинитив совершенного вида: "Подтвердить", "Закрыть",
  "Выгнать", "Сдаться". Не "Подтвердите", не "Закрывать".
- Живой игровой русский, без калек. Проверенные ловушки машинного перевода:
  - `{N} second Stun` - это "Оглушение на {N} сек.", а не "{N} второе
    Оглушение": second здесь секунда, а не порядковое.
  - Сокращение уже несёт точку: "на 5 сек." в конце фразы, а не "сек..".
  - Не "Длит.:" и "Перез.:" посреди фразы, а "длительность", "перезарядка".
  - deny - "добить" / "денай", а не "отказ"; repick - "перевыбрать", а не
    "реплика"; Kick - "Выгнать", а не "Удар"; Concede - "Сдаться", а не
    "Уступить" и не "сдача".
- Staff of the Master в описаниях - "Посох Мастера" (ключ названия предмета
  при этом английский).

## Поля способностей

| Ключ | Назначение | Переводить |
|---|---|---|
| `Ability_X_name` | Название | нет |
| `Ability_X_description_simple` | Краткое описание в тултипе - главное | да |
| `Ability_X_description` | Полное описание, показывается не всегда | да |
| `Ability_X_description2` | Дополнительный блок, обычно Посох Мастера | да |
| `Ability_X_IMPACT_effect` | Механика в подробном тултипе | да |
| `State_X_FRAME_effect` | Описание эффекта на юните | да |

Суффиксы после двоеточия (`:ult_boost`, `:OnlyMidMap`) - варианты той же
строки для Посоха Мастера и Mid Wars. Переводи их так же, как основную строку,
с учётом отличий в оригинале.

## Проверка

```sh
make lint            # дефекты перевода
make untranslated    # что осталось без перевода
```

`make lint` ловит большую часть правил выше. Длину кнопок он не проверяет:
её видно только в игре.
