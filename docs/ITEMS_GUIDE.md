# Работа с переводом предметов (Items)

Общие правила - в [TRANSLATION_GUIDE.md](TRANSLATION_GUIDE.md), здесь только
то, что касается предметов.

## Где находятся предметы

Все предметы - в `bundle/entities_en.str`, ключи начинаются с `Item_`:

```
Item_AxeOfTheMalphai_name                  Axe of the Malphai
Item_AxeOfTheMalphai_description_simple    ...описание в магазине...
Item_AxeOfTheMalphai_shop_flavor           ...лор...
```

Нужный предмет ищи по английскому имени ключа: `Item_BloodArmor`,
`Item_MysticVestments`, `Item_MarkofthePredator`.

## Поля предмета

| Ключ | Что это | Что делать |
|---|---|---|
| `Item_X_name` | Название предмета | не переводить |
| `Item_X_description_simple` | Описание в магазине - главное | переводить |
| `Item_X_description` | Полное описание; в игре часто пустое | переводить, если не пустое |
| `Item_X_description2` | Дополнительный блок (Посох Мастера, бонусы) | переводить |
| `Item_X_IMPACT_effect` | Что делает активное применение | переводить |
| `Item_X_effect_header` | Заголовок блока эффектов | переводить, имя внутри - английское |
| `Item_X_shop_flavor` | Лорный текст в магазине | переводить художественно |
| `Item_X_shop_categories` | Фильтры магазина (`Filter_Damage`) | не переводить |
| `Item_X_search_terms` | Слова для поиска в магазине | английские не трогать, русские можно дописать |

`Item_X_shop_categories` - служебные идентификаторы, а не текст. Видимое имя
фильтра лежит отдельно, в `Shop_Filter_*_description`. Переведённый токен
(`Фильтр_Урон` вместо `Filter_Damage`) выкидывает предмет из фильтра.

`Item_X_search_terms` - через запятую, без пробелов вокруг запятых. Удалять
английские слова нельзя: по ним ищут. Русские допиши в конец:

```
Item_AbyssalFlower_search_terms    abyssalflower,flower,...,цветок,бездна
```

## Правила для описаний

- Коротко: описание показывается в небольшом тултипе.
- Пассивный эффект начинай с "Пассивно:" или "При ...".
- Активный эффект - глагол действия в третьем лице: "Применяет", "Создаёт",
  "Наносит".
- Аура - начинай с "Аура:".
- Числа и подстановки `{...}` - строго как в оригинале.

## Лор (shop_flavor)

- Свободный художественный перевод, главное - атмосфера.
- В шрифтах игры есть и прямые кавычки, и ёлочки. Внутри одной строки не
  смешивай.

## Сокращения

| Длинная форма | Сокращение |
|---|---|
| скорость движения | скор. движ. |
| скорость атаки | скор. атаки |
| перезарядка | не сокращать |
| максимальное здоровье | макс. здоровье |
| регенерация здоровья | реген. здоровья |
| магическая броня | маг. броня |
| за секунду | в сек. |
| физический урон | физ. урон |
| магический урон | маг. урон |

Сокращение уже несёт точку: "на 5 сек." в конце фразы, а не "сек..".

## Проверка

1. Правь `bundle/entities_en.str`.
2. `make lint` - дефекты перевода.
3. `make run`, затем в игре открой магазин и найди предмет: текст должен
   влезать в тултип.

## Типичные проблемы

| Проблема | Решение |
|---|---|
| Текст не влезает в тултип | Сократи описание |
| Предмет пропал из фильтра магазина | В `_shop_categories` переведён токен - верни английский |
| Цвет растёкся до конца тултипа | Не закрыт цветовой код, добавь `^*` |
| Текст не обновился | Перезапусти игру, а не только карту |
