# Как устроен порт под Windows

Установка и удаление - в [корневом README](../README.md).

Всё написано на встроенном PowerShell 5.1: без Python, 7-Zip и прав
администратора. `install.bat` и `uninstall.bat` нужны только для запуска
двойным кликом, логика в `lib/`.

## Когда раскладываются файлы

Так же, как на Linux (см. [linux/README.md](../linux/README.md)): лаунчер
сверяет каталог игры со своим манифестом и на любой лишний файл отвечает
"требуется обновление".

Ярлык "HoN (RU)" запускает `lib/apply.ps1` со скрытой консолью. Скрипт
собирает строки, сам запускает `juvio.exe`, ждёт в логе лаунчера строку
`Delegating to the entry point` и кладёт файлы в
`heroes of newerth\stringtables`. После выхода из игры файлы убираются.

Поэтому игра на русском, только если запущена через этот ярлык. Родной ярлык
Juvio и ссылки `hon://` запускают её на английском.

Если лаунчер в этом запуске скачал патч, база строк у скрипта уже от старой
версии. Такой запуск идёт на английском, со следующего всё как обычно.

## Чем читается архив игры

Строки в `resources0.jz` сжаты zstd, встроенные средства Windows для zip его
не читают. Скрипт перебирает по порядку:

1. `tar.exe` из Windows 11 - он собран с zstd (проверяется по `tar --version`).
   В Windows 10 `tar` есть, но без zstd.
2. Готовый `zstd.exe`: в папке `windows\`, в `%LOCALAPPDATA%\hon-ru\`, в PATH,
   в Git for Windows.
3. Скачивание официальной сборки zstd 1.5.7 с GitHub в
   `%LOCALAPPDATA%\hon-ru\`. Версия закреплена, файл сверяется по SHA-256.
4. Если скачать не вышло - окно со ссылкой: скачать архив вручную и положить
   `zstd.exe` из него в папку `windows\`.

Для `zstd.exe` оглавление zip (ZIP64, архив больше 4 ГБ) разбирается самим
скриптом. Строки собираются побайтно так же, как на Linux.

## Если игра стоит не там

Путь к игре берётся из реестра, куда его пишет установщик Juvio. Если игру
перенесли вручную и скрипт её не находит, создайте `windows\config.local.ps1`
(он в `.gitignore`):

```powershell
$HonGameDir = 'D:\путь\до\Juvio\heroes of newerth'
$HonDocsDir = 'D:\путь\до\Documents\Juvio\Heroes of Newerth'
```

Там же `$HonUseTar = $false` отключает встроенный `tar`, и скрипт всегда
берёт `zstd.exe`.

## Что где лежит

- `%LOCALAPPDATA%\hon-ru\` - журналы `install.log` и `apply.log`, скачанный
  `zstd.exe`, исходные значения `startup.cfg`. Удаляется `uninstall.bat`.
- `startup.cfg` - скрипт выставляет `host_locale` и `host_backuplocale` в
  `en` (обычно они такие и есть) и возвращает прежние значения при удалении.
- Кеш игры (`filecache`, `webcache`) чистится, когда меняется перевод.
