# Как устроен порт под Windows

Установка и удаление - в [корневом README](../README.md).

Всё написано на встроенном PowerShell: ничего доустанавливать не нужно, права
администратора тоже.

## Когда подключается перевод

Лаунчер Juvio проверяет файлы игры и на любой лишний файл требует обновление.
Поэтому перевод не лежит в папке игры постоянно. Ярлык "HoN (RU)" запускает
игру, ждёт, пока лаунчер закончит проверку, и только тогда подкладывает файлы
перевода. После выхода из игры они убираются.

Поэтому игра на русском, только если запущена через этот ярлык. Родной ярлык
Juvio и ссылки `hon://` запускают её на английском.

Если лаунчер в этом запуске скачал патч, игра пойдёт на английском, со
следующего запуска всё как обычно.

## Обновление

При каждом запуске через ярлык скрипт сверяет перевод и свои файлы с веткой
master на GitHub.

- Новый перевод скачивается в `%LOCALAPPDATA%\hon-ru\bundle` и используется
  вместо `bundle/` из папки русификатора. `install.bat` эту копию стирает:
  после распаковки нового архива она может оказаться старее.
- Если изменились сами скрипты, игроку предлагают скачать новый архив. Про
  одну и ту же версию спрашивают один раз.
- Без сети или если GitHub не отвечает, игра запускается на том, что уже
  есть.

## Чем читается архив игры

Тексты игры лежат в сжатом архиве, который обычные средства Windows не
открывают. В Windows 11 хватает встроенного `tar`. В Windows 10 скрипт один
раз скачивает с GitHub официальную утилиту `zstd.exe` и сверяет её
контрольную сумму. Если скачать не вышло, появится окно со ссылкой: скачайте
архив вручную и положите `zstd.exe` из него в папку `windows\`.

## Если игра стоит не там

Путь к игре берётся из реестра, куда его пишет установщик Juvio. Если игру
перенесли вручную и скрипт её не находит, создайте `windows\config.local.ps1`:

```powershell
$HonGameDir = 'D:\путь\до\Juvio\heroes of newerth'
$HonDocsDir = 'D:\путь\до\Documents\Juvio\Heroes of Newerth'
```

## Что где лежит

- `%LOCALAPPDATA%\hon-ru\` - журналы `install.log` и `apply.log` (пригодятся,
  если что-то не работает), скачанный перевод и служебные файлы. Удаляется
  `uninstall.bat`.
- Язык в настройках игры остаётся английским: русский текст подставляется
  вместо английского. `uninstall.bat` возвращает настройки как были.
- Когда меняется перевод, скрипт чистит кеш игры.
